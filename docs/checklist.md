## V1-d（1回目）: 設定モーダルと JSON入出力

**ここから実際に登録できます。** 初回は［設定］から部署 → 担当者の順に登録してください。

### 設定モーダル（CLAUDE.md 5.8）

- [ ] ［設定］を押すとモーダルが開く
- [ ] ［閉じる］ボタンと Esc キーで閉じられる
- [ ] 部署を追加できる（入力欄で Enter でも追加できる）
- [ ] 部署名を書き換えると、その場でガント側の見出しも変わる
- [ ] 部署の右に所属人数が出ている
- [ ] 担当者を追加できる（名前＋所属部署を選ぶ）
- [ ] 部署が1つも無いあいだは、担当者を追加できない状態になっている
- [ ] 担当者の名前・案件数・絵文字・一言コメントをその場で書き換えられる
- [ ] 書き換えるとすぐガントの担当者ヘッダに反映される（保存ボタンは無い）
- [ ] 案件数・絵文字・コメントは空のままでもよい
- [ ] 担当者の所属部署を変えると、ガント側の並びと部署の人数表示が両方変わる

### 削除の制約（CLAUDE.md 5.8）

- [ ] 担当者がいる部署を削除しようとすると、赤いメッセージで拒否される
- [ ] 担当者が0人の部署は、確認ダイアログのあと削除できる
- [ ] ある案件の唯一の担当者を削除しようとすると、案件名入りのメッセージで拒否される
- [ ] 複数担当の案件しか持たない担当者は、確認のあと削除できる（案件からは担当が外れる）

### 書き出し（CLAUDE.md 5.9）

- [ ] ［書き出し］を押すと `sgantt-backup-YYYYMMDD-HHMM.json` がダウンロードされる
- [ ] ダウンロードしたファイルをテキストエディタで開くと中身が読める

### 読み込み（CLAUDE.md 5.9）

- [ ] ［読み込み］でファイルを選ぶと「すべて置き換えます」と件数が出る
- [ ] ［キャンセル］すると何も変わらない
- [ ] ［OK］すると内容が置き換わり、画面も切り替わる
- [ ] **書き出したファイルを読み込むと、元どおりになる**
- [ ] 関係ないファイル（例: 適当なテキスト）を選ぶと、理由が出て**いまのデータは残る**

## V2-a: バーのドラッグ移動（CLAUDE.md 5.10）

**バーを掴んで動かせるようになりました。** 伸縮（端を引っぱって期間を変える）は次の V2-b です。

### 移動

- [ ] バーにマウスを乗せると、掴めることを示すカーソル（手の形）になる
- [ ] バーをドラッグすると、1日ずつぴったり動く（中途半端な位置で止まらない）
- [ ] バーの長さは変わらない
- [ ] 上下にドラッグしても、別の担当者・別の案件には移らない
- [ ] MT・入稿・納品の文字も同じようにドラッグで動かせる（1日のまま）
- [ ] 手を離した時点で保存される（保存ボタンは無い）
- [ ] 同じ案件が複数の担当者の下に出ている場合、両方の行が同時に動く

### クリックとの使い分け

- [ ] バーを「ただクリック」するとポップアップが開く（従来どおり）
- [ ] バーを「ドラッグ」したときはポップアップが開かない
- [ ] ほんの少し（4px 未満）動いてしまった場合はクリック扱いになる

### 取り消し

- [ ] ドラッグ中に Esc キーを押すと、元の位置に戻って保存されない

### 表示期間の制限

- [ ] 表示している期間の外へはドラッグできない（左端・右端で止まる）
- [ ] 期間の外へ動かしたいときは、ポップアップの日付欄で変更する
- [ ] 画面の端まで持っていっても、自動でスクロールはしない（仕様どおり）
- [ ] 表示期間からはみ出しているバーは、はみ出す向きへは動かせない
      （期間内へ戻す向きには動かせる）

### 伸縮

- [ ] 色付きバー（初校・修正・ラフ）の左右の端にマウスを乗せると、左右矢印のカーソルになる
- [ ] 右端を引っぱると、開始日はそのままで終了日だけが変わる
- [ ] 左端を引っぱると、終了日はそのままで開始日だけが変わる
- [ ] 1日ずつぴったり変わる
- [ ] 端から離れた「バーの真ん中あたり」を掴んだときは、これまでどおり移動になる
- [ ] 手を離した時点で保存される

### 最小幅と交差

- [ ] 右端を左へ大きく引っぱっても、1日分より短くならない
- [ ] 左端を右へ大きく引っぱっても、1日分より短くならない

### MT・入稿・納品

- [ ] MT・入稿・納品の端を掴んでも伸縮しない（移動になり、1日のまま）

### 表示期間の制限・取り消し

- [ ] 表示期間の外へは伸ばせない（左端・右端で止まる）
- [ ] 伸縮の途中で Esc キーを押すと、元の長さに戻って保存されない

### 細いバーでの掴みしろ（CLAUDE.md 5.10 掴みしろの縮退）

列幅は最低 42px あるため、**通常の使い方ではこの状態になりません**。
将来 `css/style.css` の `--col-width` を小さくしたときのための備えです。

- [ ] （参考）列幅を極端に狭めても、掴みしろがバー本体を覆い尽くさない
