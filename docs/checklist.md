## V1-a: 骨格とカレンダー

### 期間コントロール（CLAUDE.md 5.2）

- [ ] 初めて開いたとき、開始日が「今日の7日前」・幅が「30日間」になっている
- [ ] ［7日］を押すと、開始日が今日の7日前・幅が7日間になる
- [ ] ［30日］を押すと、開始日が今日の7日前・幅が30日間になる
- [ ] 開始日を直接変えると、その日から表示が始まる
- [ ] 終了日を直接変えると、幅がその日までに変わる
- [ ] 終了日に開始日より前の日を入れると、1日間に補正される（入力欄も直る）
- [ ] 120日を超える期間を入れると、120日に補正される（入力欄も直る）
- [ ] 期間を変えてページを再読み込みしても、同じ期間で開く

### 日付ヘッダ（CLAUDE.md 5.3）

- [ ] 各列に「月/日」と曜日（日〜土）が出ている
- [ ] 今日の列が黄色くなっている
- [ ] 日曜・祝日の列が薄い赤になり、日付の文字も赤い
- [ ] 土曜の列が薄い水色になり、日付の文字も青い
- [ ] 土曜が祝日の日は、水色ではなく赤になる
- [ ] 日付にマウスを重ねると「2026-09-21 敬老の日」のように日付と祝日名が出る
- [ ] 今日が土日祝と重なる日は、黄色（今日）が優先される
- [ ] 期間を長くすると、日付グリッドが横スクロールできる
